# Дополнительные корневые сертификаты для сборки

Если сеть подменяет TLS (корпоративный прокси), положите сюда корневой сертификат в PEM с расширением `.crt`.
Стадии сборки `deps` доверяют всем `*.crt` из этой папки (`NODE_EXTRA_CA_CERTS`). Файлы `*.crt` в git не попадают.
В итоговый образ (nginx) сертификаты не копируются.
